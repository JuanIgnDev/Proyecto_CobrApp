# CobrApp

Sistema web para la gestión de clientes y cobranzas.
Este sistema robusto, permite llevar una trazabilidad de clientes, con sus respectivas cuentas.
Permite actualizar, crear, eliminar y ver informacion de los clientes, estadisticas generales de ventas y cobros.
Exportacion a pdf.
Enviar mails o whatsApp.
Notificaciones automaticas para X cantidad de tiempo ocurrido sin cobrar una cuenta de un cliente.
Configuracion de la app, cambios de tema para mejorar la experiencia de usuario.
